# PC-Monitor

Графический монитор ресурсов компьютера на PyQt6. Приложение показывает загрузку
процессора и памяти, использование дисков, сетевую скорость и состояние батареи.
Показатели обновляются каждые 1,5 секунды.

## Структура проекта

- `get_*_info.py` — низкоуровневое получение метрик через `psutil`.
- `pc_monitor/services/` — сбор метрик и расчёт сетевой скорости.
- `pc_monitor/models.py` — типизированные модели снимка системы.
- `pc_monitor/ui/` — главное окно, виджеты и тема оформления.
- `pc_monitor/app.py` — создание и запуск приложения.
- `main.py` — точка входа.

## Запуск

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Запустите приложение:

```bash
python main.py
```
